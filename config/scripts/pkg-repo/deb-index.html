Unicon Debian repository

Components, one per line in sources.list:

  • dev — snapshots built from master
  • rc — release candidates
  • stable — the latest release
  • 13.3 — the current minor release

Enable one of them. There is no major-only component. The graphics build is this repository. The --disable-graphics build is a second repository, unicon-nographics, with the same components. Do not enable both for the same component: the no-graphics package sorts as a newer unicon.

# add the archive key
curl -fsSL https://deb.unicon.org/unicon/keys.gpg | sudo tee /usr/share/keyrings/unicon-archive.gpg > /dev/null

# dev, rc, stable, or 13.3
UNICVER=stable
echo "deb [signed-by=/usr/share/keyrings/unicon-archive.gpg] https://deb.unicon.org/unicon $(lsb_release -sc) $UNICVER" | sudo tee /etc/apt/sources.list.d/unicon.list

sudo apt update && sudo apt install unicon

No-graphics build (no GUI, IDE, or 3D library):

echo "deb [signed-by=/usr/share/keyrings/unicon-archive.gpg] https://deb.unicon.org/unicon-nographics $(lsb_release -sc) $UNICVER" | sudo tee /etc/apt/sources.list.d/unicon-nographics.list

Suites currently built: Debian 12 (bookworm), Debian 13 (trixie), Ubuntu 22.04 (jammy), Ubuntu 24.04 (noble), Ubuntu 26.04 (resolute). amd64 and arm64.
